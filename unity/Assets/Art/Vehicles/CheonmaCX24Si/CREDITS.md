# Seorak Cheonma CX-24Si

Modelled for The Tarmac Gauntlet from Ivan's reference renders, using the car modelling workflow in `docs/car-modelling.md`.
Build scripts: `tools/cars/cheonma/`.
Name lettering: Unbounded ExtraBold (SIL Open Font License).
Seorak badge: the game's own brand mark.

Units are metres. Forward is +Z, up is +Y, origin is mid wheelbase on the ground.
