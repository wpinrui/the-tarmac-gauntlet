# Kaiser Scream

Modelled for The Tarmac Gauntlet from Ivan's reference model, using the car modelling workflow in `docs/car-modelling.md`.
Build scripts: `tools/cars/scream/`.
Kaiser badge and the Unbounded font (SIL Open Font License, `tools/cars/scream/font/`): the game's own brand mark and type.

Units are metres. Forward is +Z, up is +Y, origin is mid wheelbase on the ground.
